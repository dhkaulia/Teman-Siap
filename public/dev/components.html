Komponen UI Teman Siap

Komponen modular bebas dependensi, ramah sentuhan (min 48px), navigasi keyboard & pembaca layar (screen reader).

1. ChoiceTiles

Single & Multi

Pilihan besar dengan ikon, label, hint, warna aktif, dan ikon centang (✓).

Mode Tunggal (Radio):

Pilihan: tenang

Mode Banyak (Checkbox):

Pilihan: istirahat

2. BodyMap

Somatik

Peta tubuh SVG interaktif untuk mengenali lokasi ketegangan fisik saat emosi hadir.

Sensasi terpilih: (belum ada)

3. Breather

Regulasi 4-4-6

Animasi lingkaran napas berbasis CSS transform murni (tanpa reflow layout). Mendukung jeda & reduced motion.

4. Wave (Urge Surfing)

Intensitas 0-10

Gelombang dorongan belanja. Geser vertikal untuk mengubah intensitas, atau putar animasi ombak.

5. Keypad

Format Rupiah

Papan angka mandiri dalam aplikasi. Tidak memicu popup keyboard OS seluler.

Nilai numerik: 0

6. BottomSheet

Modal Geser

Panel geser bawah dengan pegangan drag, swipe-down, backdrop tap, dan focus trap.

7. Bubble

Refleksi

Gelembung pesan refleksi tenang untuk panduan, catatan pribadi, dan respon pasangan.
